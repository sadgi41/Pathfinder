# SkillPath AI 🚀

An interactive career progression platform that helps developers analyze skill gaps, measure job readiness, generate personalized learning roadmaps, and track progress in real time.

---

## ✨ Features

### 🎯 Role-Based Skill Analysis
Compare your current role with your target role (e.g. Junior Frontend → Senior Frontend).

### 📊 Smart Readiness Scoring
Calculates readiness based on:
- Existing skills
- Skill proficiency levels
- Completed learning progress

### 🛣 Personalized Learning Roadmap
Automatically generates:
- Beginner learning steps
- Advanced learning milestones

Based on your missing skills.

### ✅ Progress Tracking
Users can:
- Mark skills as completed
- Remove completed skills from roadmap
- See live dashboard updates

### 🌙 Dark Mode
Toggle between light and dark mode.

### 📱 Fully Responsive
Works across:
- Mobile
- Tablet
- Desktop

Clone the repository:

Move into project:

cd skillpath-ai

Install dependencies:

npm install

Run locally:

npm run dev
